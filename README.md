# Олександ Тимошенко — Архітектурне портфоліо

Сучасне, швидке та стильне портфоліо архітектора, створене з використанням нативного HTML, CSS та JavaScript. Дизайн-система заснована на естетиці та принципах **Anthropic (Claude)**, використовуючи теплі кольори, плавну типографіку (Lora & Inter) та м'які пружинні мікро-анімації.

## Ознаки та особливості
- **Темна тема за замовчуванням** з можливістю перемикання на світлу.
- **Glassmorphism** — ефект матового скла для навігаційної панелі та модальних вікон.
- **Premium Animations** — плавні появи контенту, skeleton loading (shimmer effect) та scroll progress bar.
- **Вбудований PDF-Viewer** — перегляд робочих креслень та альбомів прямо на сайті за допомогою `pdf.js`.
- **Адаптивність (Mobile-First)** — ідеальне відображення на мобільних пристроях, планшетах, десктопах та навіть надвеликих 4K екранах.
- **Без фреймворків** — чистий, семантичний код без використання важких бібліотек типу React чи Bootstrap, що гарантує максимальну швидкість завантаження.

## Структура проєкту
```
/
├── index.html       # Головна сторінка портфоліо
├── styles.css       # Дизайн-система та всі стилі
├── script.js        # Логіка (анімації, теми, PDF viewer)
├── assets/          # Ресурси (картинки, PDF-документи)
│   ├── images/
│   └── documents/
└── docs/            # Документація (гайдлайни дизайну Anthropic)
```

## Встановлення та запуск
Проєкт є повністю статичним. Для його перегляду достатньо:
1. Завантажити репозиторій.
2. Відкрити `index.html` у будь-якому сучасному браузері.

Для коректної роботи завантаження PDF-файлів рекомендується запускати проєкт через локальний сервер (наприклад, розширення Live Server у VS Code або `npx http-server`).

## Дизайн-система
У проєкті імплементовано **Anthropic Design System**. Основні CSS-змінні (токени) винесені у `styles.css`. Щоб змінити колірну гаму, радіуси чи шрифти, достатньо змінити значення у блоці `:root` або `[data-theme="light"]`.
